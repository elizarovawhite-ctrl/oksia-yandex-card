# Рендер слайдов Историй ОКСИЯ

Слайды Историй (сторис) верстаются в `slide.html` и рендерятся скриншотом в PNG 1280×1920.
AI-генерацию картинок для текстовых сторис не используем — нет контроля над кириллицей,
переносами, кеглем, цветом.

## Файлы

- `slide.html` — параметрический шаблон. `?n=` выбирает слайд:
  - `n=1..10` — история «Подготовка к школе»
  - `n=11..15` — обложки историй: 11 Семейные классы, 12 Дополнительные занятия,
    13 Педагоги, 14 Как проходят занятия, 15 Как записаться
- `bg-tb.png` / `bg-top.png` / `bg-bottom.png` / `bg-blue.png` — фон-плашки,
  нарезаны из акварельного фона клиента (`src017.jpg` — это `images/img017.jpg` до переделки):
  волны сверху+снизу / только сверху / только снизу / сплошной синий (для инверт-слайдов).
- `src017.jpg` — исходный фон, чтобы можно было перенарезать плашки.

## Как рендерить

1. Поднять локальный сервер в этой папке: `python -m http.server 8777 --bind 127.0.0.1`
2. Через browser MCP:
   - `browser_navigate` → `http://127.0.0.1:8777/slide.html?n=N`
   - `browser_evaluate`: `() => document.fonts.ready.then(() => { document.documentElement.style.zoom='4'; return 'ok'; })`
   - `browser_take_screenshot` scale=`css` → выходит ровно 1280×1920
   - Трюк с zoom=4: вьюпорт браузера тут 5120×7680 при DPR 0.25, поэтому zoom 4 масштабирует
     страницу до размера вьюпорта, а css-скриншот делит обратно → 1:1 1280×1920.
     Если вьюпорт другой — сначала `browser_resize(1280,1920)` (он сам вернёт 5120×7680 DPR 0.25).
3. Готовые PNG → в `images/imgNNN.jpg` панели (конвертировать в JPG quality 90) и в кабинет Яндекса.

## Стиль (закреплено, не менять без её слова)

- Заголовки: **Playfair Display 800**. Подписи/капс: **PT Serif**.
- Кремовый `#FBF5E9`, бронза `#8A5A1B`, синий текст `#3C5C77`, голубая плашка `#E3EBF1`.
- Разные композиции по слайдам (волны сверху/снизу, текст центр/слева, 1-2 инверт-слайда) —
  чтобы серия не выглядела «забором».
- Без висячих строк, без длинных тире, без счётчика слайдов.
- В сторис только вечная информация. Даты пробных → раздел «События» карточки.
