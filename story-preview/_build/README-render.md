# Рендер слайдов Историй ОКСИЯ

Слайды Историй (сторис) верстаются в `slide.html` и рендерятся скриншотом в PNG 1280×1920.
AI-генерацию картинок для текстовых сторис не используем — нет контроля над кириллицей,
переносами, кеглем, цветом.

## Файлы

- `slide.html` — параметрический шаблон. `?n=` выбирает слайд, по 10 на историю
  (первый номер каждой десятки — обложка):
  - `n=1..10`  — Подготовка к школе
  - `n=11..20` — Семейные классы
  - `n=21..30` — Дополнительные занятия
  - `n=31..40` — Педагоги
  - `n=41..50` — Как проходят занятия
  - `n=51..60` — Как записаться
  - параметры слайда: `bg` (tb/top/bottom/blue), `align:'left'`, `inv:true`,
    `ds` (кегль заголовка), `ns` (кегль числа), `isize` (размер иконки), `ghost` (водяной знак)
- `bg-tb.png` / `bg-top.png` / `bg-bottom.png` / `bg-blue.png` — фон-плашки,
  нарезаны из акварельного фона клиента (`src017.jpg` — это `images/img017.jpg` до переделки):
  волны сверху+снизу / только сверху / только снизу / сплошной синий (для инверт-слайдов).
- `src017.jpg` — исходный фон, чтобы можно было перенарезать плашки.

## Как рендерить

Проверенный способ (сентябрь 2026) — Chrome headless, без browser MCP и без сервера,
файл открывается по `file://`. Скрипт: `scratchpad/render_stories.py` (весь цикл: рендер
n=11..60 → PNG → JPG q90 в `images/imgNNN.jpg` + копии в `story-preview/slides/` и обложки
в `story-preview/covers/`).

    chrome --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
      --font-render-hinting=none --window-size=1280,1920 --virtual-time-budget=9000 \
      --screenshot=out.png "file:///.../slide.html?n=N"

Выходит ровно 1280×1920, шрифты Google Fonts подгружаются (нужен интернет).
Проверять глазами каждую партию — Chrome не жалуется на обрезанный текст (`overflow:hidden`).

Старый способ через browser MCP (`zoom='4'` + css-скриншот при DPR 0.25) тоже работает,
но 50 слайдов через тул-вызовы долго — скрипт быстрее.

Готовые JPG → в кабинет Яндекса (Истории), обложки историй = первый слайд каждой десятки.

## Стиль (закреплено, не менять без её слова)

- Заголовки: **Playfair Display 800**. Подписи/капс: **PT Serif**.
- Кремовый `#FBF5E9`, бронза `#8A5A1B`, синий текст `#3C5C77`, голубая плашка `#E3EBF1`.
- Разные композиции по слайдам (волны сверху/снизу, текст центр/слева, 1-2 инверт-слайда) —
  чтобы серия не выглядела «забором».
- Без висячих строк, без длинных тире, без счётчика слайдов.
- В сторис только вечная информация. Даты пробных → раздел «События» карточки.
